Post Editor

A clean two-panel writing interface for drafting posts before they enter the CMS. Supports headline (auto-generates slug), subheadline, rich-text body, endnote, tags, flags, publish/expiration dates, canonical URL, and video URL. Autosaves to your browser. When you're ready, "Open in CMS" pre-fills all supported fields in Athena automatically.

Visit navybook.com/D1/seo/add-post.html

Headline Lab

Reads your article body and returns six AI-generated options for headline, subheadline, and slug — each tuned for SEO and the publication's voice. Powered by the Anthropic Claude API.

Appears as a button in the CMS post editor sidebar. Requires the Athena Tools Chrome extension.

UI Tweaks

Reorders CMS post editor fields and groups publish date and status into a cleaner bar. Runs quietly in the background — nothing to click.

Automatic on any Athena CMS post editor page when the Athena Tools Chrome extension is installed.

Skybox Push

Cascades an article through skybox slots 1–5 in the pub's skybox admin. Slot 1 gets a clean slate; existing overrides travel with each article as it shifts down. Sponsored slots (and everything below them) are never touched.

Use the bookmarklet on any GE360 article page. Opens the skybox admin and handles the cascade automatically.

Trending Topics

Pulls GA4 traffic data, scores topics by day + week + month views, and surfaces the top 7 recommendations for review. You can apply them in one click or adjust before saving. Runs automatically each night at 5:00 am for Defense One and Washington Technology.

Available on the D1-Trending items list page in the Athena CMS. Requires the Athena Tools Chrome extension. Nightly automation runs without any action needed for D1 and WT.

Earthbox Auto-Updater

Populates editorial Earthbox slots with the top GA4 articles for each pub. Sponsored slots are detected automatically and left untouched. Runs nightly at 5:30 am for Defense One and Washington Technology.

Fully automated for D1 and WT — no action needed. Results appear on the Daily Updates page.

Daily Updates

A daily digest showing what the nightly scripts changed across all five pubs — topics and earthboxes, with new items bolded and sponsored slots called out inline. Active pubs sort first; inactive pubs show a "no auto-updates" note.

Visit navybook.com/D1/updates/
